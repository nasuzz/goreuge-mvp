# 합성 데이터 정책

- 실제 메신저·메일·금융 개인정보를 사용하지 않습니다.
- 대표 페르소나 기반 시연 문장 3~5건과 평가 문장 20건을 제작합니다.
- 각 문장에 정답 JSON을 붙입니다.
- AI 평가 결과에는 반드시 `합성 데이터 기준`이라고 표시합니다.
- AI가 원문에 없는 소득유형·날짜·금액을 임의로 확정하지 않는지 평가합니다.

## 필수 변형

- `240만원`, `2,400,000원`, 한글 금액
- 익월 말일, 완료 후 30일, 검수 후 지급
- 금액·날짜 누락
- 본문 내 정보 충돌
- VAT 포함·별도
- 선금·잔금 분할
- 지급일 변경 메시지
