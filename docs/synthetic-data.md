# 합성 데이터 정책

- 실제 메신저·메일·금융 개인정보를 사용하지 않습니다.
- 대표 페르소나 기반 시연 문장 3~5건과 평가 문장 20건을 제작합니다.
- 각 문장에 정답 JSON을 붙입니다.
- AI 평가 결과에는 반드시 `합성 데이터 기준`이라고 표시합니다.
- AI가 원문에 없는 소득유형·날짜·금액을 임의로 확정하지 않는지 평가합니다.

## 구현 데이터

- 평가셋: `data/ground-truth/contract-evaluation.json`
- 시연 선정본: `data/fixtures/demo-contract-messages.json`
- 기준일: `2026-09-01` (연도가 생략된 문장의 날짜 해석에 사용)
- 평가 명령: `pnpm run test:ai`

평가셋은 정확히 20건이며 각 문장에 핵심 8개 필드의 정답을 포함합니다. 현재 160/160 수치는 **합성 데이터 기준 fallback 파서 필드 일치 결과**이며 실제 OpenAI 모델 정확도나 실제 카카오톡·메일 전체에 대한 일반 정확도로 표현하지 않습니다.

## 필수 변형

- `240만원`, `2,400,000원`, 한글 금액
- 익월 말일, 완료 후 30일, 검수 후 지급
- 금액·날짜 누락
- 본문 내 정보 충돌
- VAT 포함·별도
- 선금·잔금 분할
- 지급일 변경 메시지
- 지급처 실수령액 직접 안내, 공제액 안내, 안내 금액 충돌

## 개인정보·시연 원칙

- 실제 팀원·지인·고객의 메시지를 복사하지 않습니다.
- 거래처 이름과 금액은 모두 가상입니다.
- 외부 AI에는 거래처명·계좌번호를 placeholder로 마스킹한 원문만 전송합니다.
- 화면과 발표자료에 “합성 데이터” 배지를 표시합니다.
- AI 후보는 사용자가 확인하기 전 DB에 저장하지 않습니다.
